## 1. 요청 내용

### 요청 원문

테스트환경에서 회원가입페이지에서 테스트가입만들고 default값을 채워서 가입성공하도록 추가

### 확인한 요구사항 요약

테스트환경의 에이블리 회원가입 화면에 테스트용 가입 버튼을 추가해, 클릭 시 필수값이 기본값으로 자동 채워져 가입이 바로 성공하도록 하는 요청이다. 개발 시 이 버튼이 테스트환경에서만 노출되도록 분기 처리해야 한다.

## 2. 요구사항 전체

| 순번 | 요구사항 | 성격 | 비고 |
|---|---|---|---|
| 1 | 회원가입 화면에 '테스트 가입' 버튼을 추가한다 (테스트환경에서만 노출) | 개발 | — |
| 2 | 테스트 가입 버튼 클릭 시 회원가입에 필요한 입력값을 default값으로 자동 채운다 | 개발 | — |
| 3 | default값이 채워진 상태로 가입 요청을 처리해 가입이 성공하도록 한다 | 개발 | — |

## 3. 개발 범위

- 요구사항 1 — 회원가입 화면에 '테스트 가입' 버튼을 추가한다 (테스트환경에서만 노출)
- 요구사항 2 — 테스트 가입 버튼 클릭 시 회원가입에 필요한 입력값을 default값으로 자동 채운다
- 요구사항 3 — default값이 채워진 상태로 가입 요청을 처리해 가입이 성공하도록 한다

## 5. 완료 조건

- 테스트환경 회원가입 화면에 테스트 가입 버튼이 표시된다
- 테스트 가입 버튼을 누르면 필수 입력값이 자동으로 채워진다
- 채워진 default값으로 가입을 진행하면 가입이 성공 처리된다
- 운영환경에서는 테스트 가입 버튼이 노출되지 않는다

## 6. 정한 것

- 테스트 가입 버튼의 노출 범위(운영환경 노출 여부)를 정해야 한다 → 원문이 '테스트환경에서'라고 명시했으므로 테스트환경에서만 노출하고 운영환경에서는 노출하지 않는다 (AI 권장안)
