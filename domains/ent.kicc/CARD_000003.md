# KICC 카드 배치키 발급 요청 API (CARD_000003)

- 처리: 읽기·쓰기
- 화면 겸함: 아니오
- 상태: 따라감

## 부르는 화면

| 화면ID | 화면 이름 | 요소 |
|---|---|---|
| HIT-CONF-10-S | 엔터프라이즈 주 충전수단 조회 화면 | 화면 |

## 입력

- 거래일자 (TRX_DT)
- 거래번호 (TRX_SEQ)
- 카드번호 (CARD_NO)
- PASSWORD
- AUTH_VALUE
- EXPIRY_DATE

## 출력

- 응답코드 (RES_CD)
- 응답메시지 (RES_MSG)

## 데이터 처리

### 카드거래원장 pg 거래번호 조회 (TB_CARD_TRAN_R002)

- 종류: SELECT
- 테이블: TB_CARD_TRAN
- 입력: 거래일자 (TRX_DT), 거래구분 (TRX_TP), 거래번호 (TRX_SEQ), 처리상태 (PROC_ST)

### 카드거래원장 등록 (TB_CARD_TRAN_C001)

- 종류: INSERT
- 테이블: TB_CARD_TRAN
- 입력: 거래일자 (TRX_DT), 거래번호 (TRX_SEQ), 거래구분 (TRX_TP), ORDER_NO, MALL_ID, BATCH_KEY, GOODS_NM, AUTHORIZATION_ID, 결제금액 (AMT), PG_CNO, MSG_AUTH_VALUE, REQ_DATA, 회원코드 (MEMB_CD), 응답코드 (RES_CD), 응답메시지 (RES_MSG), 처리상태 (PROC_ST)

### 카드거래원장 수정 (TB_CARD_TRAN_U001)

- 종류: UPDATE
- 테이블: TB_CARD_TRAN
- 입력: RES_DATA, 응답코드 (RES_CD), 응답메시지 (RES_MSG), 처리상태 (PROC_ST), MSG_AUTH_VALUE, PG_CNO, 거래일자 (TRX_DT), 거래구분 (TRX_TP), 거래번호 (TRX_SEQ)

### 계좌목록조회 (TB_ACCOUNT_R001)

- 종류: SELECT
- 테이블: TB_ACCOUNT, TB_BANK, TB_ZEROPAY_BANK
- 입력: 회원코드 (MEMB_CD), DYNAMIC_0

### 카드원장 개인 시퀀스 조회 (TB_CARD_SEQ_R001)

- 종류: SELECT
- 테이블: TB_CARD
- 입력: 회원코드 (MEMB_CD)

### 카드원장 등록 (TB_CARD_C001)

- 종류: INSERT
- 테이블: TB_CARD
- 입력: 회원코드 (MEMB_CD), 회원코드 (MEMB_CD), ISSUER_CODE, ISSUER_NAME, ACQUIRER_CODE, ACQUIRER_NAME, BATCH_KEY, MASK_CARD_NO, CARD_GUBUN, CARD_BIZ_GUBUN, MAIN_CARD_YN

- 공통 헤더 처리(이 업무 아님): TB_APP_MNG_R001
