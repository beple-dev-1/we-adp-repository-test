# 요기요 주문결제 API 호출 (bp_ygyo_pay_c005)

- 처리: 읽기·쓰기
- 화면 겸함: 아니오
- 상태: 따라감

## 부르는 화면

| 화면ID | 화면 이름 | 요소 |
|---|---|---|
| BPG-YGYO-20-10-S | 요기요 결제 | 화면 |

## 입력

- PAID_AT
- ORDER_DT
- ORDER_ID
- 할인금액 (SALE_AMT)
- EVENT_NM

## 출력

- 코드 (CODE)
- MSG

## 데이터 처리

### 요기요 주문원장 조회(ORDER_DT, ORDER_ID) (TB_BP_AFLT_ODR_R026)

- 종류: SELECT
- 테이블: TB_BP_AFLT_ODR_PDT, TB_BP_AFLT_ODR, TB_YGYO_ODR
- 입력: ORDER_DT, ORDER_ID, 주문유형 (ORDER_TYPE)

### 비플페이 거래내역 조회(ORDER_DT, ORDER_ID) (TB_BPPAY_TRAN_R002)

- 종류: SELECT
- 테이블: TB_MNY_CHRG_WDRW_DTL, TB_YGYO_ODR, TB_MEMBER, TB_CAFETERIA_MENU, TB_BPPAY_TRAN, TB_CAFETERIA_ODR, TB_CAFETERIA_OPEN_HOUR
- 입력: ORDER_ID, ORDER_DT, 거래구분 (TRX_TP)

### 비플페이 복합결제 거래내역 조회(TRX_DT,TRX_SEQ,TRX_TP) (TB_BPPAY_COMPLEX_TRAN_R001)

- 종류: SELECT
- 테이블: TB_BPPAY_COMPLEX_TRAN
- 입력: 거래일자 (TRX_DT), 거래번호 (TRX_SEQ), 거래구분 (TRX_TP), DYNAMIC_0

### 요기요 주문 원장 업데이트 (TB_YGYO_ODR_U001)

- 종류: UPDATE
- 테이블: TB_YGYO_ODR
- 입력: CART_ID, SHOP_ID, SHOP_NAME, MENU_TOTAL_AMOUNT, SERVING_TYPE, 회원코드 (MEMB_CD), ORDER_STATE, ACCEPTED_DTTM, USE_SAFETY_NUMBER_YN, USER_MESSAGE, USE_DISPOSABLE_YN, CANCELED_YN, CANCEL_REASON, CANCELED_DTTM, DELIVERY_LAT, DELIVERY_LNG, DELIVERY_ADDRESS, DELIVERY_ADDRESS_DETAIL, DELIVERY_FEE, DELIVERY_EXPECTED_DTTM, PICKUP_LAT, PICKUP_LNG, PICKUP_ADDRESS, PICKUP_ADDRESS_DETAIL, PICKUP_CODE, PICKUP_EXPECTED_DTTM, PICKUP_BARCODE_URL, PAYMENT_TRANSACTION_NUMBER, TOTAL_AMOUNT, PAID_DTTM, UPDATED_DTTM, CREATED_DTTM, BP_AFLT_ODR_DT, BP_AFLT_ODR_ID, BADGE_YN, SHOP_ADDRESS, ORDER_DTL_STATE, EXTRA_PAYMENT_AMOUNT, 사업자번호 (BIZ_NO), MEMB_CANCEL_REQ_YN, YGYO_ORDER_DT, YGYO_ORDER_ID

### 주문원장 처리상태 업데이트 (TB_BP_AFLT_ODR_U003)

- 종류: UPDATE
- 테이블: TB_BP_AFLT_ODR
- 입력: ORDER_PROC_ST, 처리상태 (PROC_ST), CAN_DEVICE, BILL_NO, DEAL_NO, 배송지ID (AREA_ID), EXT_ORDER_NO, ORDER_ID, ORDER_DT, ORDER_TYPE

- 공통 헤더 처리(이 업무 아님): TB_APP_MNG_R001, TB_MEMBER_APP_R001
