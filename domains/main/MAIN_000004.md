- 종류: SELECT
- 테이블: TB_EMAIL
- 입력: 회원코드 (MEMB_CD), ATCH_NAME

### 온라인PG 거래내역 조회 (by TRX_DT, TRX_SEQ) (TB_ZEROPAY_PG_TRAN_R003)

- 종류: SELECT
- 테이블: TB_ZEROPAY_PG_TRAN, TB_TRAN
- 입력: 거래일자 (TRX_DT), 거래번호 (TRX_SEQ)

### 비플PG 거래내역 조회 (by TRX_DT, TRX_SEQ) (TB_ZEROPAY_BPPG_TRAN_R003)

- 종류: SELECT
- 테이블: TB_ZEROPAY_BPPG_TRAN, TB_TRAN
- 입력: 거래일자 (TRX_DT), 거래번호 (TRX_SEQ)

### 거래내역 확인서 발급내역 조회 (TB_TRAN_COMFIRMATION_R001)

- 종류: SELECT
- 테이블: TB_TRAN_CONFIRMATION
- 입력: 거래일자 (TRX_DT), 거래코드 (TRX_CD), 업무코드 (BIZ_CD), 거래번호 (TRX_SEQ)

### 가맹점정보 조회 (TB_AFFILIATION_MNG_R001)

- 종류: SELECT
- 테이블: TB_AFFILIATION_MNG, TB_AFFILIATION_MY
- 입력: 가맹점ID (AFLT_ID)

### 비플페이 가맹점정보 조회(BP_AFLT_SEQ) (TB_BP_AFLT_MNG_R001)

- 종류: SELECT
- 테이블: TB_BP_AFLT_MNG, TB_BP_AFLT_UPJONG
- 입력: 비플가맹점순번 (BP_AFLT_SEQ)

### 거래확인서 발급내역 등록 (TB_TRAN_COMFIRMATION_C001)

- 종류: INSERT
- 테이블: TB_TRAN_CONFIRMATION
- 입력: 거래일자 (TRX_DT), 거래코드 (TRX_CD), 업무코드 (BIZ_CD), 거래번호 (TRX_SEQ), 거래일자 (TRX_DT), FILE_NM, 회원코드 (MEMB_CD)

### 거래내역 확인서 발급내역 업데이트 (TB_TRAN_COMFIRMATION_U001)

- 종류: UPDATE
- 테이블: TB_TRAN_CONFIRMATION
- 입력: 거래일자 (TRX_DT), FILE_NM, 회원코드 (MEMB_CD), 거래일자 (TRX_DT), 거래코드 (TRX_CD), 업무코드 (BIZ_CD), 거래번호 (TRX_SEQ)

### 이메일 발송 목록 추가 (TB_EMAIL_C001)

- 종류: INSERT
- 테이블: TB_EMAIL
- 입력: 회원코드 (MEMB_CD), 앱코드 (APP_CD), 제목 (TITLE), CONTENT, 처리상태 (PROC_ST), RECV_EMAIL, SEND_EMAIL, SEND_DTTM, EMAIL_SEQ, ATCH_YN, ATCH_PATH, ATCH_NAME

- 공통 헤더 처리(이 업무 아님): TB_APP_MNG_R001, TB_MEMBER_APP_R001
