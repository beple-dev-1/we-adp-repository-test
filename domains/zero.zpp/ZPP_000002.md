# 제로페이 포인트 결제요청 (ZPP_000002)

- 처리: 읽기·쓰기
- 화면 겸함: 아니오
- 상태: 따라감

## 부르는 화면

| 화면ID | 화면 이름 | 요소 |
|---|---|---|
| MGC-GIFT-20-S | 상품권 구매(금액·결제수단) | 화면 |

## 입력

- 은행코드 (BANK_CD)
- 계좌번호 (ACCT_NO)
- 계좌SEQ (ACCT_SEQ)
- 주문일자 (ODR_DT)
- 주문번호 (ODR_NO)
- 거래구분 (TRX_TP)

## 출력

- 주문번호 (ODR_NO)
- 사용자번호 (USER_NO)
- 거래구분 (DEAL_DIV_CD)
- 판매채널코드 (SALE_CHANNEL)
- 상품금액 (PRDT_AMT)
- 상품명 (PRDT_NM)
- CALL_BACK_URL
- 응답코드 (RSPS_CD)
- 거래번호 (TNO)
- 은행코드 (BANK_CD)
- 계좌번호 (ACCT_NO)
- 고객명 (USER_NM)
- 반환URL (RETURN_URL)

## 데이터 처리

### 계좌상세조회(BY KEY) (TB_ACCOUNT_R002)

- 종류: SELECT
- 테이블: TB_ACCOUNT
- 입력: 회원코드 (MEMB_CD), 거래번호 (SEQ)

### 제로페이 포인트 주문정보 조회 (TB_ZEROPAY_GIFT_ODR_R001)

- 종류: SELECT
- 테이블: TB_ZEROPAY_GIFT_ODR
- 입력: ORDER_DT, ORDER_ID

### 제로페이 포인트 주문정보 업데이트 (TB_ZEROPAY_GIFT_ODR_U002)

- 종류: UPDATE
- 테이블: TB_ZEROPAY_GIFT_ODR
- 입력: 은행코드 (BANK_CD), 계좌번호 (ACCT_NO), PRE_RETV_TNS_NO, ORDER_STS, PAY_STS, ORDER_DT, ORDER_ID

### 모바일 판매채널코드로 구분상세코드조회 (TB_APP_LOCAL_MNG_R005)

- 종류: SELECT
- 테이블: TB_APP_LOCAL_MNG
- 입력: SELL_CHNL_CD, GIFT_TP, 지역코드 (LOC_CD), 앱코드 (APP_CD), MAIN_YN

- 공통 헤더 처리(이 업무 아님): TB_APP_MNG_R001, TB_MEMBER_APP_R001
