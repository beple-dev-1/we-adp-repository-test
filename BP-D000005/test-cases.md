# BP-D000005 · 참고용 테스트 케이스

Builder 가 요청서의 완료 조건과 화면 외 구현에서 먼저 적은 테스트 케이스입니다. **참고용**입니다.

## 단위테스트 — 화면 외 구현 항목마다

없음.

## 통합테스트 — 완료 조건마다

| 완료 조건 | TC |
|---|---|
| 소식이 0건인 가맹점에서 '아직 등록된 소식이 없어요.' 와 '새로운 소식으로 고객에게 가게를 알려 보세요.' 두 줄이 보인다. | TC-001 |
| 소식이 1건 이상이면 안내 문구가 보이지 않는다(현재 동작 그대로). | TC-002 · TC-003 |
| 안내 영역의 마크업과 클래스는 변경 전과 같다. | TC-004 |
