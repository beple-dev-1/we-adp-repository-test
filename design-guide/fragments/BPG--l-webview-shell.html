비플페이 회원일 경우 별도의 요기요 회원가입 없이 요기요 주문 서비스를 이용할 수 있습니다.

단, 비플페이 배달 최초 접근 시 위치정보 사용 동의 및 주문을 위한 고객 정보 제공에 동의 해주셔야 이용할 수 있습니다.

[주문 내역에서 문의하기]
요기요 주문 → 주문 내역 → 주문내역 상세 → 가게보기 → 가게 상세 원산지 → 전화번호 선택하여 직접 통화 가능하십니다.

[매장 상세에서 문의하기]
요기요 주문 → 원하는 가맹점 → 가게 상세 원산지 → 전화번호 선택하여 직접 통화 가능하십니다.

비플페이 내 요기요 주문에서는 익스프레스, 편의점, 마트 등 일부 가맹점이 노출되지 않아 요기요 앱과 검색 결과가 다를 수 있습니다.

등록된 매장 정보 또는 전화번호가 실제 매장 정보와 다를 경우, 요기요 고객센터로 문의 주시기 바랍니다.

[고객센터 이용 방법]
요기요 주문 메인 → 우측 고객센터 버튼 → 요기요 상담톡

요기요 주문 상단 주소 정보를 눌러 위치를 재설정할 수 있습니다.
현 위치 검색 시 휴대전화의 위치설정 및 위치 권한을 켜주시기를 바랍니다.

비플페이 내 요기요 주문 배달 종류는 현재 가게 배달만 지원하고 있습니다.
빠른 시일 내에 익스프레스 배달도 가능하도록 준비하도록 하겠습니다.

지역별로 배달할 수 있는 매장의 수가 차이가 날 수 있습니다.
빠른 시일 내에 고객님의 지역에 배달할 수 있는 매장을 확보하여 서비스하도록 하겠습니다.

현재 비플페이 내 요기요 주문 서비스에는 리뷰 기능이 없습니다.
빠른 시일 내에 리뷰 기능 준비하도록 하겠습니다.

가장 최근에 반영된 주소 체계로 검색을 해주셔야 합니다.
예를 들어 '미아1동'은 현재 '삼양동'으로 행정동 이름이 변경되었습니다.
예) '미아1동, 미아2동' → '삼양동' / '봉천11동' → '인헌동'

최신 주소 검색을 위해 http://www.juso.go.kr 이 사이트를 참고하시어 요기요 주문 서비스를 이용해주시기 바랍니다.

최근 주소 삭제를 원하시는 경우 하단과 같은 방법으로 삭제해주세요.

[주소 관리 방법]
요기요 주문 메인 → 좌측 주소영역 선택 → 편집 → 삭제/수정 선택

[즐겨찾기 추가 방법]

2. 가맹점 상세 우측 즐겨찾기 버튼 선택

[즐겨찾기 위치]
요기요 주문 메인 > 상단 즐겨찾기 아이콘 선택

안심번호는 주문자의 개인 정보 보호를 위해 실제 연락처가 노출되지 않도록 050으로 시작하는 임시 가상번호가 발급되는 서비스입니다.

안심번호는 일정 시간이 지난 후 자동 해지됩니다.

요기요 주문 서비스는 비회원 기반으로 회원 탈퇴가 없습니다.
비플페이 탈퇴 시 요기요 주문 서비스 정보도 삭제되며, 비플페이 재가입 한다고 하여 이전에 사용하시던 주문내역을 조회 할 수 없습니다.

요기요 주문 서비스는 비회원 서비스로, 요기요'의 회원 정보가 관리되지 않습니다.
비플페이 회원 정보를 변경하고 싶으실 경우 비플페이 앱을 재 설치 하신 후 변경된 정보를 통해 본인닝증을 완료하면 지속적인 서비스 이용이 가능합니다.

요기요 주문 서비스는 비회원 기반으로 회원 탈퇴가 없습니다.
비플페이 탈퇴 시 요기요 주문 서비스 정보도 삭제됩니다.

[주문 방법]
1. 요기요 주문 메인
2. 가맹점 선택 (포장/배달 선택)
3. 메뉴 선택
4. 옵션 선택
5. 장바구니 담기
6. 결제

주문하신 내역은 요기요 주문 메인 > 주문명세에서 확인하실 수 있습니다.

주문한 음식의 배달여부 및 배달소요 시간 등에 궁금하실 경우 매장으로 직접 문의하시면 더욱 빠르게 답변받으실 수 있습니다.
매장 문의 방법은 아래와 같습니다.

[매장 문의 방법]

매장에서 주문을 수락한 후에는 메뉴정보를 수정할 수 없습니다.
추가 문의가 있다면 매장에 직접 연락해 주세요.

추가 문의가 있다면 매장에 직접 연락해 주세요.

매장에서 주문을 수락한 후에는 요청사항을 수정할 수 없습니다.
추가 문의가 있다면 매장에 직접 연락해 주세요.

주문이 완료되면 메인에 주문 상태 툴팁이 노출됩니다. 자세한 주문 내역은 하단 방법으로 확인해 주세요.

[주문내역 확인방법]
요기요 주문 메인 > 주문 내역

음식의 경우 조리예(이미지)와 다소 차이가 있을 수 있습니다.
주문하신 음식은 해당 음식점에서 직접 제공되므로, 음식의 맛에 대한 불만, 실제 배달받은 상품과 상이함을 이유로 인한 환불 및 교환, 보상은 어려운 점 양해 부탁드립니다.
음식 품질 관련 문의는 주문하신 가게로 문의 부탁드립니다

[매장에 문의하기]
요기요 주문 → 주문 내역 → 주문내역 상세 → 가게보기 → 가게 상세 원산지 → 전화번호 선택하여 직접 통화 가능하십니다.

다만, 음식에서 이물이 확인된 경우 하단 방법으로 문의 부탁드립니다.
[고객센터 이용 방법]
요기요 주문 메인 → 우측 고객센터 버튼 → 요기요 상담 톡

이용에 불편을 드려 대단히 죄송합니다. 안내받으신 도착 예정 시간은 가게에서 제공한 시간으로, 주문량 및 날씨, 교통상황 등의 상황에 따라 실제 도착시간은 다소 차이가 날 수 있으며, 실제 도착시간이 배달 에성시간 보다 지연되었음을 이유로 한 환불이나 별도의 보상이 어려운 점 양해 부탁드립니다.

정확한 주문 접수와 주문 확인을 위해 반드시 상시 연락이 가능한 휴대전화 번호를 입력해 주셔야 합니다. 휴대전화 번호가 없거나 연락이 되지 않는 경우 주문이 불가능하며, 주문을 해주셔도 취소될 수 있사오니 이 점 이용에 유의 바랍니다.

식사 시간에 언짢은 일을 겪게 해드려 죄송합니다.
음식에서 이물이 발견된 경우, 식품안전나라 홈페이지 또는 고객센터를 통해 직접 신고하거나 2019년 7월 16일부터는 배달앱 업체를 통해서도 식약처에 대리 신고가 가능합니다.

2. 식품안전나라 통합민원 상담 서비스 홈페이지를 통한 신고
　(홈페이지 : https://www.foodsafetykorea.go.kr/minwonMainNew.do)

▣ 요기요를 통한 대리 신고 방법

주문하신 가게로 문의 부탁드립니다

[매장 문의 방법]
요기요 주문 → 주문내역 → 주문내역 상세 → 가게보기 → 가게 상세 원산지 → 전화번호 선택하여 직접 통화 가능하십니다.

가게마다 등록되어 있는 최소 주문 금액은 상이합니다.
고객님이 주문하고자 하는 가게를 선택하시면, 가게명 아래에서 확인할 수 있습니다.
또는 가게 정보 페이지 → 결제정보에서도 확인하실 수 있습니다.

주문 시 결제 화면에서 타인의 휴대전화 번호를 입력하여 주문하실 수 있습니다.
다만, 주문과 관련된 정보를 입력하신 휴대전화 번호로 안내해 드리므로, 신중하게 입력 부탁드립니다

요기요 포장 서비스 사용 시, 가맹점주와 사용자가 주문을 확인할 수 있도록 제시하는 교환 코드입니다.

[포장 교환 코드 위치]
요기요 주문 메인 > 주문내역 > 주문내역 상세 > 교환 코드 선택

요기요 주문은 비플 머니로 결제하실 수 있습니다.
비플 머니 연결 계좌 같은 경우 아래 방법으로 관리 가능하십니다.

[결제 화면에서 설정]
요기요 주문 결제 화면 -> 결제 수단 '비플 머니 계좌 등록 / 계좌 정보 선택'

* 비플 식권을 사용하는 기업일 경우 비플 식권으로도 결제가 가능합니다.

주문이 아직 수락되지 않은 경우, '주문 취소' 후 결제수단을 변경하여 재구매하실 수 있습니다.
주문이 이미 수락되었거나 배달이 완료된 경우, 결제수단 변경이 어려우니 양해 부탁드립니다.

주문 영수증은 주문내역에서 확인하실 수 있으며 비플머니 전자영수증은 내역에서 확인하실 수 있습니다.

[주문 영수증 확인 방법]
요기요 주문 > 주문내역 > 주문내역 상세 > 영수증 보기

[비플머니 전자영수증 발급 방법]
비플페이 메인 → 내역 → 내역 상세 → 전자영수증 발급

[비플머니 사용시]
비플머니를 사용하여 결제하셨을 경우 일괄로 연말에 소득공제 자료를 한꺼번에 제출하고 있어 연말 공제 내역에서 확인하실 수 있습니다.
사용하신 비플머니 전자영수증은 비플페이 메인 > 내역에서 확인하실 수 있습니다.

비플머니는 1만원 단위로 충전이 가능합니다.
결제 수단을 비플머니로 선택하여 결제하는 경우, 잔액이 부족하면 연결 계좌에서 1만원 단위로 자동 충전되어 결제됩니다.
비플머니 충전 내역 및 관리는 비플페이 메인 → 계좌에서 제로페이 결제 → 비플머니에서 확인 하실 수 있습니다.
충전된 비플머니는 1000원 이상 부터 자유롭게 인출하실 수 있습니다.

[비플머니 충전 내역 및 관리 방법]
비플페이 메인 → 계좌에서 제로페이 결제 → 비플머니

[비플머니 충전 방법]
비플페이 메인 → 계좌에서 제로페이 결제 → 비플머니 → 충전하기

[자동 충전 가능 계좌]
농협, 우리, 신한, 하나, 기업, 부산, 우체국, 대구, 새마을 금고, 광주, 경남, 씨티, 신협, 전북, 수협, 제주, 산업, 케이뱅크, 카카오

[제로페이 가맹점 비플머니 사용 방법]
1. 비플페이 메인
2. 계좌에서 제로페이 결제
3. 비플머니
4. 전국 제로페이 가맹점에서 사용 가능

비플머니는 비플페이에서 제공하는 간편 결제 서비스입니다.
1 비플머니는 1원과 동등한 가치를 가지고 있으며, 제로페이 가맹점 또는 요기요 주문 시 모든 가맹점에서 사용하실 수 있습니다.
비플 머니 자동 충전 계좌가 연결되어 있으면 간편하게 결제 하실 수 있습니다.

비플 식권을 사용하는 기업의 직원인 경우 노출되는 결제 수단으로 기업에서 사용하는 식권이 노출됩니다.

일부 기업은 선택에 의하여 식권 사용 불가할 수도 있습니다.

사전 승인 완료 후 결제를 시도해 주세요. 사전 승인되지 않았을 경우 포인트(식권) 사용이 어렵습니다

[사전승인 방법]
1. 비플페이 메인

3. 사전승인 완료
4. 요기요 결제 진행

[식권 사용 방법]
1. 요기요 주문 결제
2. 결제 수단(포인트 사용)선택
3. 함께 결제, 혼자 결제 선택 (함께 결제 불가 식권일 경우 미 노출)
4. 사용 금액 입력 (차액이 있으면 비플머니로 결제 가능)
5. 요기요 주문 완료

* 식권 사용은 기업 선택사항으로 일부 기업은 사용 불가할 수도 있습니다.

비플페이에 등록한 비플머니 계좌 정보가 있는지 확인 부탁드립니다.
그럼에도 결제가 되지 않는다면 비플페이 고객센터로 문의 부탁드립니다.

주문 취소 시, 일반적으로 당일 내 결제 취소가 진행됩니다.

다만, 이용하신 결제사에 따라 취소 기간이 상이하며 최대 3~5영업일이 소요될 수 있습니다.

비플 바우처 카드는 지자체 시스템에 등록된 연락처와 비플페이에 가입한 연락처가 동일할 경우에만 결제 수단으로 노출됩니다.
두 연락처가 다를 경우, 결제 수단에 바우처 카드가 노출되지 않으며, 관할 지자체에 문의하셔서 연락처 정보를 동일하게 등록하시면, 비플 바우처 카드가 정상적으로 노출됩니다.

더 자세한 도움이 필요하신 경우, 아래 고객 센터로 문의해 주세요.
바우처 고객센터 1600-3027 (평일 09:00~18:00)

비플 바우처 카드는 경상남도 지역의 요기요 가맹점에서만 사용하실 수 있습니다.
다른 지역의 요기요 가맹점에서는 사용할 수 없습니다.

1회 사용 한도는 지자체별로 상이하며, 지자체의 정책에 따라 00시부터 06시까지는 결제가 제한될 수 있습니다.
정확한 기준은 관할 지자체의 운영 정책에 따라 다를 수 있으니 참고 부탁드립니다.

비플 바우처 카드는 당일 결제 당일 취소만 가능합니다.
만약, 가게 사정에 의해 익일 취소가 진행된 경우, 바우처 고객센터 1600-3027(평일 09:00~18:00)를 통해 문의해 주시면 도움을 드리도록 하겠습니다.
